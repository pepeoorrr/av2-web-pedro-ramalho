🚀 COMO COMEÇAR? (3 PASSOS RÁPIDOS)
════════════════════════════════════════════════════════════════════════════════

PASSO 1: PREPARAR BANCO DE DADOS
   1. Abrir MySQL:
      mysql -u root -p
   
   2. Criar banco:
      CREATE DATABASE sistema_agendamento;
      EXIT;

PASSO 2: INICIAR BACKEND (Terminal 1)
   cd backend
   npm install
   npx prisma migrate dev --name initial
   npm run seed               # Opcional: popular dados de teste
   npm run dev

   ✅ Você verá: "Servidor rodando em http://localhost:3000"

PASSO 3: INICIAR FRONTEND (Terminal 2)
   cd frontend
   npm install
   npm run dev

   ✅ Navegador abrirá: http://localhost:5173
